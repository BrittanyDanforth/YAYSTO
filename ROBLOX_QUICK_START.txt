⚡ 3 EASY STEPS TO GET STARTED:

┌─────────────────────────────────────────────────────────┐
│ STEP 1: ADD THE SCRIPT                                  │
└─────────────────────────────────────────────────────────┘
1. Open Roblox Studio
2. Go to: StarterPlayer → StarterPlayerScripts
3. Insert a LocalScript
4. Paste contents of "RobloxVFX_MainScript.lua"
5. Save!

┌─────────────────────────────────────────────────────────┐
│ STEP 2: MAKE OBJECTS INTERACTIVE                        │
└─────────────────────────────────────────────────────────┘
1. Select ANY part in Workspace
2. In Properties, find "Attributes"
3. Click + button
4. Add attribute:
   Name: VFXInteractive
   Type: Boolean
   Value: ✓ (checked)

┌─────────────────────────────────────────────────────────┐
│ STEP 3: PLAY AND TEST!                                  │
└─────────────────────────────────────────────────────────┘
1. Press Play (F5)
2. Walk near your interactive object
3. Press E
4. BOOM! 💥 EPIC VFX!

═══════════════════════════════════════════════════════════
    🚨 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════

Not working?
  ➜ Check script is in StarterPlayerScripts
  ➜ Verify object has VFXInteractive attribute
  ➜ Make sure you're close enough (10 studs)

No prompt showing?
  ➜ Double-check attribute spelling
  ➜ Attribute must be type: Boolean
  ➜ Value must be checked (true)

Too laggy?
  ➜ Reduce particle count
  ➜ Lower beam count
  ➜ Don't spam E too fast!
