═══════════════════════════════════════════════════════════════════════════
    🎨 EGG MODEL STRUCTURE
═══════════════════════════════════════════════════════════════════════════

EggModel (Model)
│
├── EggBase (Part or MeshPart)
│   ├── Your egg mesh/union here
│   ├── Material: Any
│   ├── Anchored: true
│   └── CanCollide: false
│
├── Aura (Part) ← GLOW SPHERE
│   ├── Shape: Ball
│   ├── Material: Neon
│   ├── Color: Any (will be overridden)
│   ├── Size: Vector3.new(2, 2, 2)
│   ├── Transparency: 1 (starts hidden)
│   ├── Anchored: true
│   ├── CanCollide: false
│   └── PointLight
│       ├── Brightness: 2
│       ├── Range: 10
│       └── Color: Any (will be overridden)
│
├── RingBurst (Part) ← RING EXPLOSION
│   ├── Shape: Cylinder
│   ├── Material: Neon
│   ├── Color: Any (will be overridden)
│   ├── Size: Vector3.new(1, 1, 1)
│   ├── Transparency: 1 (starts hidden)
│   ├── Anchored: true
│   ├── CanCollide: false
│   └── Orientation: Vector3.new(0, 0, 90)
│
└── SparkleAttachment (Attachment) ← OPTIONAL
    └── ParticleEmitter
        ├── Enabled: false (script enables it)
        ├── Lifetime: NumberRange.new(0.5, 1)
        ├── Rate: 50
        ├── Speed: NumberRange.new(5, 15)
        ├── Color: ColorSequence (any)
        ├── Size: NumberSequence (0.5 → 0)
        └── LightEmission: 1


═══════════════════════════════════════════════════════════════════════════
    🔨 STEP-BY-STEP CREATION
═══════════════════════════════════════════════════════════════════════════

STEP 1: Create the Model
┌─────────────────────────────────────────────────────────┐
│ 1. Insert → Model                                       │
│ 2. Name it "EggModel"                                   │
└─────────────────────────────────────────────────────────┘


STEP 2: Add the Egg Base
┌─────────────────────────────────────────────────────────┐
│ 1. Insert → Part or MeshPart                            │
│ 2. Name it "EggBase"                                    │
│ 3. Move it inside EggModel                              │
│ 4. Properties:                                          │
│    - Size: Vector3.new(3, 4, 3) (or your egg size)     │
│    - Shape: Egg or import mesh                          │
│    - Anchored: ✓                                        │
│    - CanCollide: ☐                                      │
└─────────────────────────────────────────────────────────┘


STEP 3: Add the Aura (Glow Sphere)
┌─────────────────────────────────────────────────────────┐
│ 1. Insert → Part                                        │
│ 2. Name it "Aura"                                       │
│ 3. Move it inside EggModel                              │
│ 4. Properties:                                          │
│    - Shape: Ball                                        │
│    - Size: Vector3.new(2, 2, 2)                         │
│    - Material: Neon                                     │
│    - Color: RGB(0, 255, 255) (any color)                │
│    - Transparency: 1                                    │
│    - Anchored: ✓                                        │
│    - CanCollide: ☐                                      │
│ 5. Position: Same as EggBase (centered)                 │
│                                                          │
│ 6. Add PointLight:                                      │
│    - Insert → PointLight (into Aura)                    │
│    - Brightness: 2                                      │
│    - Range: 10                                          │
│    - Color: RGB(0, 255, 255)                            │
└─────────────────────────────────────────────────────────┘


STEP 4: Add the Ring Burst
┌─────────────────────────────────────────────────────────┐
│ 1. Insert → Part                                        │
│ 2. Name it "RingBurst"                                  │
│ 3. Move it inside EggModel                              │
│ 4. Properties:                                          │
│    - Shape: Cylinder                                    │
│    - Size: Vector3.new(1, 1, 1)                         │
│    - Material: Neon                                     │
│    - Color: RGB(0, 255, 255)                            │
│    - Transparency: 1                                    │
│    - Anchored: ✓                                        │
│    - CanCollide: ☐                                      │
│    - Orientation: Vector3.new(0, 0, 90)                 │
│ 5. Position: Same as EggBase                            │
└─────────────────────────────────────────────────────────┘


STEP 5: Add Sparkle Particles (OPTIONAL)
┌─────────────────────────────────────────────────────────┐
│ 1. Insert → Attachment (into EggBase)                   │
│ 2. Name it "SparkleAttachment"                          │
│ 3. Insert → ParticleEmitter (into Attachment)           │
│ 4. Properties:                                          │
│    - Enabled: ☐ (script enables it)                     │
│    - Lifetime: NumberRange.new(0.5, 1)                  │
│    - Rate: 50                                           │
│    - Speed: NumberRange.new(5, 15)                      │
│    - SpreadAngle: Vector2.new(180, 180)                 │
│    - Acceleration: Vector3.new(0, 5, 0)                 │
│    - Size:                                              │
│      NumberSequence:                                    │
│        0 → 0.5                                          │
│        1 → 0                                            │
│    - Transparency:                                      │
│      NumberSequence:                                    │
│        0 → 0                                            │
│        1 → 1                                            │
│    - LightEmission: 1                                   │
│    - Texture: rbxassetid://6490035152 (sparkle)         │
└─────────────────────────────────────────────────────────┘


STEP 6: Position Everything
┌─────────────────────────────────────────────────────────┐
│ Select EggModel and set PrimaryPart:                    │
│   - Right-click EggModel                                │
│   - Set PrimaryPart → EggBase                           │
│                                                          │
│ Center all parts on EggBase position                    │
└─────────────────────────────────────────────────────────┘


STEP 7: Move to ReplicatedStorage
┌─────────────────────────────────────────────────────────┐
│ 1. Create folder: ReplicatedStorage → Assets            │
│ 2. Drag EggModel into Assets folder                     │
│ 3. Done!                                                │
└─────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════
    🎯 WHAT THE SCRIPT DOES WITH EACH PART
═══════════════════════════════════════════════════════════════════════════

BUILDUP PHASE:
┌─────────────────────────────────────────────────────────┐
│ Aura:                                                   │
│   - Fades in (Transparency 1 → 0.3)                     │
│   - Grows (Size 2,2,2 → 3,3,3)                          │
│   - Changes to rarity color                             │
│                                                          │
│ PointLight:                                             │
│   - Brightens (Brightness 2 → 5)                        │
│   - Expands (Range 10 → 20)                             │
│                                                          │
│ ParticleEmitters:                                       │
│   - Enabled = true                                      │
│   - Rate = 50                                           │
└─────────────────────────────────────────────────────────┘

EXPLOSION PHASE:
┌─────────────────────────────────────────────────────────┐
│ RingBurst:                                              │
│   - Appears (Transparency 0.2)                          │
│   - Expands rapidly (Size 1,1,1 → 1,12,12)             │
│   - Changes to rarity color                             │
│   - Fades out (Transparency → 1)                        │
│                                                          │
│ ParticleEmitters:                                       │
│   - Emit(100) burst                                     │
│                                                          │
│ Aura:                                                   │
│   - Flash bright (Size → 5,5,5, Transparency → 0)       │
│   - Fade out (Transparency → 1)                         │
└─────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════
    🎪 ALTERNATIVE: IMPORT YOUR OWN EGG MESH
═══════════════════════════════════════════════════════════════════════════

If you have a custom egg mesh:

1. Import as MeshPart
2. Name it "EggBase"
3. Add Aura + RingBurst parts around it
4. Follow same structure above

The VFX script only needs:
  - Aura (for glow)
  - RingBurst (for explosion)
  - Optional: ParticleEmitters

The actual egg mesh can be ANYTHING!


═══════════════════════════════════════════════════════════════════════════
    ✅ TESTING YOUR EGG
═══════════════════════════════════════════════════════════════════════════

From command bar (LocalScript):

local RS = game:GetService("ReplicatedStorage")
local player = game.Players.LocalPlayer

local EggVFX = require(RS.VFX.EggRevealVFX)
local ScreenVFX = require(RS.VFX.ScreenVFX)

local vfx = EggVFX.new(player)
vfx.ScreenVFX = ScreenVFX.new(player)

vfx:Play(RS.Assets.EggModel, {
    color = Color3.fromRGB(255, 0, 255),
    text = "Epic",
    tier = "Epic",
    petName = "Cerberage"
})
