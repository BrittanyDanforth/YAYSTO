═══════════════════════════════════════════════════════════════════════════
    🔧 CUSTOMIZATION
═══════════════════════════════════════════════════════════════════════════

Want to change values? Edit RarityConfig in the script:

local RarityConfig = {
    Common = {
        color = Color3.fromRGB(200, 200, 200), -- Change color!
        particleCount = 30,                     -- More particles!
        ringCount = 2,                          -- More rings!
        beamCount = 8,                          -- More beams!
        shakeIntensity = 0.5,                   -- Shake harder!
        flashIntensity = 0.3,                   -- Brighter flash!
        blurSize = 15,                          -- More blur!
        duration = 1.5,                         -- Longer effect!
        text = "NICE!",                         -- Change text!
        buildupTime = 0.5                       -- Longer buildup!
    },
    -- ... and same for Rare and Epic!
}


═══════════════════════════════════════════════════════════════════════════
    ❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ "Effects still appear in world, not on screen"
   ✅ Make sure you're using the NEW script!
   ✅ Old script had 3D particles, new one is 100% screen-based

❌ "Pulsing never stops"
   ✅ Fixed! Buildup now has finite pulse count
   ✅ Stops automatically after buildup duration

❌ "All rarities look the same"
   ✅ Check the VFXRarity attribute spelling
   ✅ Must be exactly: "Common", "Rare", or "Epic"
   ✅ Case-sensitive!

❌ "Prompt doesn't show"
   ✅ Part must have BOTH attributes:
      - VFXInteractive (Boolean = true)
      - VFXRarity (String)

❌ "Can trigger multiple times rapidly"
   ✅ Fixed! Now has cooldown equal to buildup + duration
   ✅ Won't trigger again until current effect finishes
