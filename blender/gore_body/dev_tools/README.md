# Dev tools used by the cloud fixer agents (copied from the cloud scratch folder)

Small helper scripts the body fix-round agents wrote while working: render harnesses (`wounds/dev.py`, `blood/dev.py`),
probes, pixel/ID-pass checks and contact-sheet makers. They are NOT part of the build. They contain cloud container
paths (`/home/user/YAYSTO/...`, `/tmp/claude-0/.../scratchpad/...`): replace those with your local repo path before use.
The body build, verify and export are `blender/gore_body/build.py` + `verify.py`.
