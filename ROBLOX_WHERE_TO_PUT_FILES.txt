═══════════════════════════════════════════════════════════════════════════
    QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

❌ "Nothing happens when I press E"
   ✅ Check: Is the script in StarterPlayerScripts?
   ✅ Check: Did you add the VFXInteractive attribute?
   ✅ Check: Are you close enough? (within 10 studs)

❌ "I don't see [E] Interact"
   ✅ Check: Attribute name is exactly "VFXInteractive"
   ✅ Check: Attribute type is Boolean (not String!)
   ✅ Check: Attribute value is checked (true)

❌ "Script has errors"
   ✅ Check: You copied the ENTIRE script
   ✅ Check: It's a LocalScript (not a regular Script)
   ✅ Check: It's in StarterPlayerScripts

❌ "Effects are too intense/laggy"
   ✅ Reduce particle count in the script
   ✅ Lower the beam count
   ✅ Decrease screen shake intensity
